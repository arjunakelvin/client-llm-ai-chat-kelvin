Admin privat

Halaman ini tidak ditautkan dari aplikasi. Masukkan admin key (secret ADMIN_KEY di worker) untuk mengelola login Discord, tier, dan akun.

Kosong = pakai API di domain ini sendiri. Isi kalau /api di domain masih ketahan proxy CORS (error Missing target URL) — isi alamat Worker Cloudflare, atau set env WORKER_URL di Vercel, atau pasang route piercingblow.ai.id/api*.

API Bot Discord (Verifikasi Akun)

Endpoint ini dipanggil oleh Bot Discord untuk memverifikasi apakah member Discord telah login/terhubung di web, serta memeriksa tier dan kuota tokennya.

GET https://piercingblow.ai.id/api/bot/verify?discord_id=123456789012345678
Header (jika Bot API Key diset): X-Bot-Key: <kunci>
Lihat contoh kode bot (JavaScript & Python)
// discord.js (v14)
const res = await fetch(`https://piercingblow.ai.id/api/bot/verify?discord_id=${interaction.user.id}`, {
  headers: { 'X-Bot-Key': 'KUNCI_BOT' }
});
const data = await res.json();
if (data.verified) {
  await interaction.reply(`Akun terverifikasi! Tier: ${data.user.tier}, Sisa token: ${data.user.tokenRemaining}`);
} else {
  await interaction.reply('Silakan login di web terlebih dahulu!');
}

# discord.py
import aiohttp
async with aiohttp.ClientSession() as session:
  async with session.get(f"https://piercingblow.ai.id/api/bot/verify?discord_id={ctx.author.id}", headers={"X-Bot-Key": "KUNCI_BOT"}) as r:
    data = await r.json()
    if data.get("verified"):
      await ctx.send(f"Terverifikasi! Tier: {data['user']['tier']}")

Server AI lokal

Dibaca aplikasi saat startup, jadi semua user otomatis mengikuti alamat server yang diset di sini. Secret ini dikirim aplikasi sebagai header X-Secret-Key (digerbang nginx) sekaligus sebagai Authorization: Bearer.
Server manager dipakai aplikasi untuk menyalakan / mematikan AI server, menampilkan status CPU/RAM/disk, dan log. Secret-nya harus sama dengan secretKey di server/servers.json.

Server manager

Semua AI server yang dikelola daemon manager (lihat server/manager.py). Alamat & secret ini disimpan di server dan ikut dibaca aplikasi web client, jadi user otomatis memakai AI server yang aktif.
