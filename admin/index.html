API Bot Discord (Verifikasi Akun)

Endpoint ini dipanggil oleh Bot Discord untuk memverifikasi apakah member Discord telah login/terhubung di web, serta memeriksa tier dan kuota tokennya.

GET https://www.piercingblow.ai.id/api/bot/verify?discord_id=123456789012345678
Header (jika Bot API Key diset): X-Bot-Key: <kunci>
Lihat contoh kode bot (JavaScript & Python)
// discord.js (v14)
const res = await fetch(`https://www.piercingblow.ai.id/api/bot/verify?discord_id=${interaction.user.id}`, {
  headers: { 'X-Bot-Key': 'KUNCI_BOT' }
});
const data = await res.json();
if (data.verified) {
  await interaction.reply(`Akun terverifikasi! Tier: ${data.user.tier}, Sisa token: ${data.user.tokenRemaining}`);
} else {
  await interaction.reply('Silakan login di web terlebih dahulu!');
}

# discord.py
import aiohttp
async with aiohttp.ClientSession() as session:
  async with session.get(f"https://www.piercingblow.ai.id/api/bot/verify?discord_id={ctx.author.id}", headers={"X-Bot-Key": "KUNCI_BOT"}) as r:
    data = await r.json()
    if data.get("verified"):
      await ctx.send(f"Terverifikasi! Tier: {data['user']['tier']}")
